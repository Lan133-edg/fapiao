# 总装分厂 · 应付与暂估数据看板

外协调度专用看板，首页分两个板块：

1. **发票统计**：各调度下推的应付台账汇总，按调度 / 年份 / 月份 / 供应商筛选，柱状图 + 扇形图可视化。
2. **暂估台账**：SAP 暂估明细（已收货未开票）分析，按年份 / 采购组 / 凭证日期区间 / 供应商 / 关键字筛选，含采购组结构、月度走势、供应商 TOP10。

访问地址：https://lan133-edg.github.io/fapiao/

### 功能

- 统计卡片：应付金额（原币）、应付金额（不含税）、记录条数、供应商数量
- 图表：各月应付金额柱状图（原币 / 不含税对比）、供应商金额占比环形图（占比低于 2.5% 的供应商合并为「其他 N 家」）、各调度应付金额柱状图

- **按调度挂账统计表**：条数、供应商数、原币 / 不含税 / 税额、金额占比、月均挂账、月份跨度，可排序、可点击筛选；该表不受「调度」筛选本身影响，便于横向对比
- 明细表：分页浏览，可导出当前筛选结果

## 二、暂估台账板块

### 数据源与口径

来源：`暂估.xlsx`（SAP 暂估明细导出，17 列，36,508 行）。

- **暂估金额 = 仍要开票金额 − 仍要交货金额**（已逐行校验，36,508 行全部吻合，差异为 0）
- **去重规则**：同一供应商、采购组、采购凭证、年份、凭证日期、物料、短文本、开票金额、暂估金额完全相同的行只保留一条。原文件存在大量重复行（最多单条重复 388 次），去重后 22,468 行，暂估金额合计由 116,426,429.91 元降至 93,881,926.05 元。
- 年份覆盖 2022—2026，其中 2026 年 18,996 行、暂估 83,073,586.88 元；页面首次进入默认选中年份筛选为最新年份，可在下拉框切到「全部年份」看全量。

### 功能

- 统计卡片：暂估金额、仍要开票金额（含暂估占比）、明细行数（含采购凭证数）、供应商 / 采购凭证
- 图表：采购组暂估金额环形图、暂估金额月度走势柱状图、供应商暂估金额 TOP10 横向条形图
- 筛选：年份、采购组、凭证日期起止区间、供应商、关键字（凭证号 / 物料号 / 短文本）
- **按采购组统计表**：明细行数、供应商数、采购凭证数、仍要开票金额、暂估金额、占比、平均每行暂估，可排序、可点击筛选
- 明细表：分页浏览，支持「按暂估金额」「按凭证日期」两种排序，可导出当前筛选结果为 Excel
- 导入：管理员模式下可导入新版暂估表（覆盖 / 追加，自动按上述规则去重）

## 三、管理员

- 入口：板块页右上角「数据管理」，密码见线下约定。
- 发票板块：添加记录、批量导入 Excel/CSV、删除、清空、恢复内置数据、导出全部。
- 暂估板块：右上角「导入新表」，同样需要管理员密码。
- 修改默认只保存在**当前浏览器**；要让所有人看到，需更新内置数据并重新发布。

## 四、技术说明

- 单文件静态应用（`index.html`），HTML + 内联 CSS/JS，无需后端。
- 图表使用 ECharts 5.5（CDN），Excel 导入导出使用 SheetJS 0.18.5（CDN）。
- 数据内联在 `const RAW`（发票）与 `const ZSUP / ZGRP / ZRAW`（暂估）中；修改数据时同步升级 `STORE_KEY` / `ZSTORE` 版本号，避免浏览器旧缓存覆盖新数据。
- 数据规模：发票 1566 条；暂估 22,468 条（压缩为数组存贮，页面约 2.3 MB）。
- 路由使用 URL hash（`#invoice` / `#accrual`），可直接分享到具体板块。
