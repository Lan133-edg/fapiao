# 应付台账汇总平台

外协调度专用：将各调度下推的应付台账汇总统计，支持按月份、供应商筛选查询，柱状图 + 扇形图可视化展示。

## 数据源

`2026年应付台账（简化版）_蓝强强10.23.xlsx`

字段口径（按要求精简）：

| 字段 | 说明 |
| --- | --- |
| 调度 | 该条台账下推的调度人员。原先的 962 条全部归入「蓝强强」，后续新增其他调度数据时按人区分 |
| 供应商名称 | 显示简称（如恒顺通、济南同工、拂尘铁龙、泰泓、可润），鼠标悬停可看全称 |
| 应付金额（原币） | 含税应付金额 |
| 应付金额（不含税） | 台账中已填写的原值，未填写则按税率倒算（见下） |
| 合同编号 | 完整合同编号 |
| 月份 | 按台账 sheet 日期取年月，精确到月 |

数据覆盖：**仅 2026 年**，共 1143 条记录、32 家供应商、3 位调度：

| 调度 | 条数 | 供应商 | 应付金额（原币） | 数据月份 |

| 刘冰 | 488 | 12 | 34,845,906.01 元 | 1—10 月 |

数据来源：

- 刘冰：《刘冰应付台账导入琦姐10.xlsx》（导入模板工作表，自带调度列）

全站应付金额（原币）合计 170,680,571.96 元、不含税合计 151,016,667.21 元。2025 年的历史数据已按要求移除。

## 功能

- 统计卡片：应付金额（原币）合计、应付金额（不含税）合计、记录条数、供应商数量
- 图表：各月应付金额柱状图（原币 / 不含税对比）、供应商金额占比扇形图、各调度应付金额柱状图（存在 2 位及以上调度时自动出现）
- 筛选：调度、年份、月份、供应商下拉筛选，合同编号 / 供应商 / 调度关键字搜索（年份、月份、供应商选项随所选调度联动）
- 明细表：分页浏览，可导出当前筛选结果为 Excel
- **按调度挂账统计表**：每位调度一行，汇总条数、供应商数、应付金额（原币 / 不含税 / 税额）、金额占比（带进度条）、月均挂账、月份跨度，底部有合计行；点表头可排序，点某一行直接把筛选切到该调度。该表**不受“调度”筛选本身影响**，只看年份 / 月份 / 供应商 / 关键字，方便横向对比各调度
- 管理员（密码 123456）：添加记录（含调度）、批量导入 Excel/CSV、删除、清空、恢复、导出全部

## 数据口径说明

- 「应付金额（不含税）」：2025 年 12 月 18 日之前的工作表原本没有该列，这部分 455 条按供应商适用税率倒算补全（默认 13%，**北京拂尘铁龙环境科技有限公司按 1%**），页面用橙色虚线标注，导出 Excel 带「不含税来源」列区分原表值与倒算值。
- 2025.12.14、2025.12.15 两个工作表中「应付金额（原币）」表头重复出现两次，第二列实际为不含税金额，页面已按不含税处理。
- 台账中「通运鑫科技有限公司」与「青岛通运鑫科技有限公司」为同一信用代码，已合并统计。
- 2025.05.23 工作表中有 3 行仅有合同编号、没有金额，未纳入统计。
- 「调度」一栏原台账中并不存在，是后加的标记字段：导入时若表格带「调度 / 负责人 / 下推人」列则按列取值，没有该列则整表归入导入面板里填写的默认调度（默认蓝强强）。
