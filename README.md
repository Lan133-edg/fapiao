# 发票信息汇总平台

外协调度专用：将各调度下推的发票进行汇总统计，支持按月份、供应商筛选查询，柱状图 + 扇形图可视化展示。

## 功能

- 📊 **统计总览**：发票总金额、张数、税额、供应商数量一览
- 📈 **可视化图表**：各月开票金额柱状图（含张数折线）、供应商金额占比扇形图
- 🔍 **快捷筛选**：按月份、供应商下拉筛选，支持合同号/单据号/供应商关键字搜索
- 📥 **批量导入**：管理员可批量导入 Excel/CSV 表格数据
- 📤 **导出**：随时导出全部或筛选结果为 Excel
- 🔐 **管理员模式**：点击右上角"数据管理"，输入管理密码后可添加、导入、删除数据

## 访问方式

开启 GitHub Pages 后，任何人都可以通过链接访问：
`https://lan133-edg.github.io/<仓库名>/`

## 数据说明

- 网页内置了 2026 年 346 条发票初始数据（来自 `发票.xlsx`）
- 管理员在网页上做的修改保存在**当前浏览器**（localStorage）中
- 如需让所有人看到新数据：管理员导出 Excel 后更新网页内置数据，或重新部署

## 发布步骤（GitHub Pages）

1. 登录 GitHub，新建仓库（如 `fapiao`，Public）
2. 将本目录中的 `index.html` 上传到仓库（网页端 Add file → Upload files，或 git push）
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main` / 目录 `/ (root)` → Save
4. 1~2 分钟后访问 `https://lan133-edg.github.io/fapiao/` 即可
