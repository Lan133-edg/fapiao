# 应付台账汇总平台

外协调度专用：将各调度下推的应付台账汇总统计，支持按月份、供应商筛选查询，柱状图 + 扇形图可视化展示。

## 数据源

`2026年应付台账（简化版）_蓝强强10.23.xlsx`

字段口径（按要求精简）：

| 字段 | 说明 |
| --- | --- |
| 供应商名称 | 显示简称（如恒顺通、济南同工、拂尘铁龙），鼠标悬停可看全称 |
| 应付金额（原币） | 含税应付金额 |
| 应付金额（不含税） | 台账中已填写的原值，未填写则显示「—」 |
| 合同编号 | 完整合同编号 |
| 月份 | 按台账 sheet 日期取年月，精确到月 |

数据覆盖：2025 年 1 月 — 2026 年 10 月，共 962 条记录，22 家供应商。

## 功能

- 统计卡片：应付金额（原币）合计、应付金额（不含税）合计、记录条数、供应商数量
- 图表：各月应付金额柱状图（原币 / 不含税对比）、供应商金额占比扇形图
- 筛选：月份、供应商下拉筛选，合同编号 / 供应商名称关键字搜索
- 明细表：分页浏览，可导出当前筛选结果为 Excel
- 管理员（密码 123456）：添加记录、批量导入 Excel/CSV、删除、清空、恢复、导出全部

## 数据口径说明

- 「应付金额（不含税）」：2025 年 12 月 18 日之前的工作表原本没有该列，这部分 455 条按供应商适用税率倒算补全（默认 13%，**北京拂尘铁龙环境科技有限公司按 1%**），页面用橙色虚线标注，导出 Excel 带「不含税来源」列区分原表值与倒算值。
- 2025.12.14、2025.12.15 两个工作表中「应付金额（原币）」表头重复出现两次，第二列实际为不含税金额，页面已按不含税处理。
- 台账中「通运鑫科技有限公司」与「青岛通运鑫科技有限公司」为同一信用代码，已合并统计。
- 2025.05.23 工作表中有 3 行仅有合同编号、没有金额，未纳入统计。
